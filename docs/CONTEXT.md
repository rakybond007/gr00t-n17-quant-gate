# 배경과 측정 근거

## 문제

VLA 정책은 행동 청크를 한 번에 내놓고 그것을 한 스텝씩 실행한다. 청크를 절반 속도로
실행하면(K2 — 인접 두 스텝을 합침) 스텝 수가 절반이 되지만, 아무 데서나 하면 실패한다.
물건을 놓치거나, 좁은 곳에 넣다가 부딪히거나, 컨트롤러 한계를 넘어 변위가 잘려나간다.

핵심 관찰은 **어디를 압축하냐가 얼마나 압축하냐보다 중요하다**는 것이다.
RoboCasa OpenDrawer 기준:

| | 성공률 | 성공시 스텝 |
|---|---|---|
| 무압축 | 0.72 | 229 |
| 무지성 K2 (전 구간) | 0.44 | 136 |
| 게이트 기반 82% 압축 | **0.68** | **178** |

## 4층 구조

1. **임베디먼트 어댑터** — RoboCasa 는 EE 델타라 인접 쌍을 더하고, 절대 관절 타겟인
   임베디먼트는 타겟을 건너뛴다.
2. **결정론적 계산층** — 액션 숫자만으로 정확히 나오는 위험 신호.
   `grip_transition`(파지 전이) · `reversal`(방향 반전) · `precise_hold`(잡은 채 저속) ·
   `infeasible_merge`(병합이 컨트롤러 한계 초과).
3. **VLM 판단층** — 계산으로 알 수 없는 **장면 정보만** 묻는다. 계산값은 질문이 아니라
   **사실로 진술**해준다.
4. **집계·증류** — noisy-OR 로 합치고 순위정규화한 뒤 소형 모듈로 증류한다.

## 측정으로 결론난 것

다시 뒤집지 말 것. 각 항목은 실측 근거가 있다.

| 결론 | 근거 |
|---|---|
| 액션 관련 문항은 묻지 말고 **계산**한다 | VLM 에게 reversal 을 물으면 AUC 0.520 — 무작위 |
| 계산값은 질문이 아니라 **사실로 진술** | 질문으로 주자 1,295 프레임의 답이 2조합으로 붕괴 |
| 스케일 기준 이미지 필수 | 그리퍼 검출 36.2% → 83.9% |
| 가중평균보다 **noisy-OR** | 검출률 4.5% → 71.6% |
| 가이던스만으론 부족, **문항도 국면 기준**이어야 | OpenDrawer 0% → 67% |
| 2콜이 8콜보다 낫다 | AUC 0.830 vs 0.763, 3.6배 빠름 |
| 모델 크기는 지연 제약이 아니다 | 파라미터 12배 키워도 0.60ms → 0.61ms (커널 런치 바운드) |
| 서로 다른 라벨로 학습된 학생의 AUC 비교는 무의미 | 증류 붕괴 감지용으로만 쓸 것 |

## 왜 공동 파인튜닝인가

게이트를 **동결된 정책에서 증류**하는 방식은 두 갈래로 시도했다.

- **독립 비전 모듈** — 자기 이미지를 직접 인코딩한다. 검증된 사전학습 인코더를 얼려 쓰는
  쪽이 손으로 짠 소형 CNN보다 낫다(프로브 val_AUC 0.734 → 0.829). 대신 백본 forward 가
  하나 더 늘어난다.
- **VLM 특징 재사용** — 정책이 이미 뽑은 특징을 빌려 쓴다. 추가 비전 연산이 0 이지만
  성능이 독립 모듈보다 낮았다. 원인으로 두 가지를 본다: 전체 토큰 평균 풀링이 텍스트까지
  섞어 공간·객체 정보를 잃었고, 애초에 **액션 예측에 맞춰진 표현**을 그대로 받는다.

두 번째의 천장을 걷어내려는 것이 이 레포다. 게이트가 자기 레이어를 읽고 액션 헤드와
함께 학습되면, unfreeze 된 상위 레이어가 두 목적을 서로 다른 깊이에서 만족하도록 움직인다.
이미지 토큰만 보는 것으로 풀링 손실도 함께 없앤다.

**단, 전제가 바뀐다.** 기존 전제는 "정책 고정, 추론 시점에만 개입"이었다. 공동 파인튜닝은
정책 자체를 바꾸므로 게이트 없는 같은 조건의 베이스라인을 따로 뽑아야 개선폭을 귀속할 수 있다.

## 라벨에 남은 문제

**D 문항이 거의 안 잡힌다.** "그리퍼가 손잡이에 닫히고 있는가"를 묻는데 전 데이터에서
한 번도 0.5 를 넘지 않았다. 원인은 계산층 중복이다 — `corr(q_D, grip_transition) = 0.75`,
집계 기여도 2.55%p. 닫힘 사건은 계산이 이미 잡으므로 VLM 에는 **잡는 대상이 고정된
손잡이인가 자유 물체인가**만 물어야 한다. 다음 라벨링에서 고칠 항목.

**noisy-OR 포화.** 계산 플래그가 0/1 이진이라 하나만 켜져도 점수가 0 이 되고, 하위 29.51%
가 전부 동점이 된다(플래그 발생과 1.0000 일치). 그 구간에서는 VLM 판단이 통째로 버려지고
순서도 무의미해진다. 심각도 비례 연속값으로 바꾸면 0.08% 로 줄고, 버려지던 VLM 신호와
상관 0.777 을 회복한다. `v6b_phase5_soft.parquet` 의 `p_yes_soft`(전부 비율) 와
`p_yes_softB`(사건형은 거의 이진 유지) 가 그 두 변형이다.

연속화의 반대급부도 실측했다. 이진 플래그가 켜졌던 청크의 24~27% 가 τ=0.5 에서 통과한다.
파지 전이나 방향 반전은 **한 번의 잘못된 병합이 곧 실패**라 비율로 희석하면 안 될 수 있어서
변형 B 를 따로 뒀다. 어느 쪽이 맞는지는 폐루프 평가로만 갈린다.
