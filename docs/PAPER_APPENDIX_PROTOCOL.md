# Appendix: 압축 신뢰도 척도의 구성과 검증 프로토콜

## A.0 이 부록이 정의하는 세 가지

압축 게이트의 신뢰도 $\mathrm{conf}$ 는 **문항으로 이루어진 측정 도구**다. 이 부록은
그 도구와, 그것을 만드는 절차와, 절차를 실행하는 소프트웨어를 구분해 기술한다.

| | 정의 | 어디에 |
|---|---|---|
| **척도** (instrument) | 문항 $Q$ 개, 부호, 가중, 등급표. 청크마다 $\mathrm{conf}\in[0,1]$ 을 낸다 | A.1 |
| **프로토콜** | 배속 평가 결과와 데이터셋에서 그 척도를 구성·검증하는 절차 | A.3 |
| **하네스** (harness) | 프로토콜을 실행하는 소프트웨어. 판정기 설정·장면 집합·지표를 고정해 서로 다른 문항 판의 결과를 비교 가능하게 만든다 | A.6 |

척도 구성은 심리측정의 **척도 개발**(scale development)과 같은 문제이고, 검증 지표도
그 용어에 대응한다.

| 이 부록의 지표 | 대응하는 표준 개념 |
|---|---|
| 유지율 상관 | criterion validity (외부 기준과의 관계) |
| 국면몫 · 위험−안전 격차 | known-groups differentiation |
| 발동률 | item analysis |
| 문항쌍 상관 | item redundancy |
| 개발집합 $D$ / 보류집합 $H$ | cross-validation sample |

**입력**은 (i) 균등 배속 평가 결과와 (ii) 시연 데이터셋 경로 둘뿐이고, **출력**은 검증된
문항 집합과 그것으로 만든 프레임 단위 라벨이다.

## A.1 표기와 정의

### 게이트

길이 $H$ 의 액션 청크마다 신뢰도 $\mathrm{conf} \in [0,1]$ 을 내고, $\mathrm{conf} \ge \tau$
이면 그 청크를 낮은 시간 해상도로 실행한다.

판정기는 정지 화면과 계산된 사실 문장을 받아 문항 $q = 1..Q$ 에 등급 $1..G$ 로 답한다.
문항마다 부호 $s_q \in \{-1,+1\}$ 와 가중 $w_q > 0$ 이 주어진다.

$$e_q = \sum_{i=1}^{G} i\,p_q(i), \qquad
g_q = \frac{e_q-1}{G-1}, \qquad
\mathrm{conf} = \frac{1}{2}\Bigl(1 + \sum_{q=1}^{Q} s_q \bar w_q g_q\Bigr)$$

$p_q(i)$ 는 판정기가 등급 토큰 $i$ 에 준 확률이다. $e_q$ 는 뽑힌 정수 등급이 아니라
그 분포의 기댓값이다.

**가중 정규화.** 부호가 같은 문항끼리 합이 1 이 되게 한다.

$$\bar w_q = \frac{w_q}{\sum_{q' : s_{q'} = s_q} w_{q'}}$$

이 규약이 $\mathrm{conf}\in[0,1]$ 을 보장한다. 문항 부분집합만 쓸 때는 남은 문항끼리
다시 정규화한다.

### 국면

청크가 조작의 어느 단계인가. 정지 화면으로 관측되지 않으므로 액션 시퀀스에서 유도한다.
유도 함수 $\phi: (\text{액션 창}) \to \mathcal{P}$ 는 로봇의 파지 기구에 따라 정의한다.
파지 개폐를 나타내는 액션 차원이 있으면 그 부호를, 없으면 파지 상태를 대신할 기하량을
쓴다(예: 양팔 손바닥 간격의 임계 통과).

### 외부 기준

셀 $c$(태스크 또는 태스크×물체)의 유지율:

$$\rho_c(K) = \frac{\text{성공}_c(K)}{\text{성공}_c(1)}$$

기준선 성공률이 낮은 셀은 비가 불안정하므로 제외한다.

### 채점표

장면 $i$ 에 대해 $y_i = \mathrm{conf}_i$, 셀 $t_i$, 국면 $p_i$ 라 하고

$$\hat\tau_i = \operatorname{mean}\{y_j : t_j=t_i\}, \qquad
r_i = y_i - \hat\tau_i, \qquad
\hat\pi_i = \operatorname{mean}\{r_j : p_j=p_i\}$$

| 지표 | 정의 |
|---|---|
| 셀몫 | $\operatorname{Var}(\hat\tau)/\operatorname{Var}(y)$ |
| 국면몫 | $\operatorname{Var}(\hat\pi)/\operatorname{Var}(y)$ |
| 남는몫 | $\operatorname{Var}(r-\hat\pi)/\operatorname{Var}(y)$ |
| 국면몫(잔차 기준) | $\operatorname{Var}(\hat\pi)/\operatorname{Var}(r)$ |
| 위험−안전 격차 | $\operatorname{mean}(y \mid p=\text{위험}) - \operatorname{mean}(y \mid p=\text{안전})$ |
| 유지율 상관 | $\operatorname{Spearman}\bigl(\operatorname{mean}(y\mid t=c),\ \rho_c(K)\bigr)$ |
| 발동률 | 문항마다 등급 $\ge 4$ 인 장면의 비율 |
| 중복 | 문항쌍 등급 상관의 최댓값 |

앞의 셋은 분모가 $\operatorname{Var}(y)$ 로 같아 서로 더하고 견줄 수 있다. 잔차 기준
국면몫은 분모가 다르므로 셀몫과 직접 비교하지 않는다.

구간추정은 장면 부트스트랩으로, 귀무분포는 국면 라벨 순열로 낸다.

## A.3 절차

**1. 국면 유도.** $\phi$ 를 정의하고 데이터셋 전체에 적용한다. 국면마다 화면을 이어
붙여 유도 결과가 의도한 단계와 일치하는지 확인한다.

**2. 장면 집합.** 국면마다 같은 수의 장면을 뽑아 개발집합 $D$ 를 만들고, 겹치지 않는
같은 크기의 보류집합 $H$ 를 만든다. 한 에피소드가 한 국면에서 차지하는 장면 수에 상한을
둔다.

**3. 라벨링.** 판정기에게 문항을 묻는다. 판정기는 답을 텍스트로 쓰고 그 텍스트를
파싱한다. 각 장면에 대해 정수 등급, 등급 분포 $p_q(\cdot)$, 기댓값 등급 $e_q$ 를
저장한다. 실행마다 문항 집합·부호·가중·문구 해시를 라벨과 함께 기록한다.

**4. 채점.** A.1 의 지표를 산출하고 아래 기준으로 판정한다.

| 기준 | 합격선 |
|---|---|
| 형식 준수 | $\ge 99\%$ |
| 발동률 | 모든 문항 $> 0$ |
| 중복 | 최대 쌍 상관 $\le 0.7$ |
| 부호 | 감점 문항은 위험 셀에서, 가점 문항은 안전 셀에서 평균 등급이 높다 |
| 유지율 상관 | $> 0$ |
| 등급 분포 적재 | $\ge 99\%$ 의 행 |

위험 셀은 $\rho_c(K)$ 하위 절반, 안전 셀은 상위 절반으로 정의한다.

**5. 반복.** 불합격 항목이 가리키는 문항 하나의 문구만 고치고 3~4 를 되풀이한다. 부호·
가중·등급표·시스템 문구는 이 단계에서 바꾸지 않는다. 전 항목 합격 시 종료한다.

**6. 가중.** 라벨 위에서 정한다. 에피소드를 둘로 갈라 한쪽에서 적합하고 다른 쪽에서
채점한다.

**7. 보류집합 확인.** 채택된 문항과 가중으로 $H$ 를 라벨링하고 4 를 되풀이한다.

**8. 역치.** 국면별 압축 허용률이 목표에 닿도록 $\tau$ 를 고른다. $D$·$H$ 는 국면균등
이므로 데이터셋의 실제 국면 비율로 가중하여 계산한다.

**9. 전량 라벨링.** 채택된 문항으로 데이터셋 전체를 라벨링하고 배포표를 만든다.

## A.4 제약

절차의 각 단계가 성립하기 위한 조건.

**C1. 문항 채점의 주 지표는 국면몫이며 셀당 지표가 아니다.** 셀당 지표를 목적함수로
쓰면 라벨이 셀 상수로 수렴하고, 그 극한에서 라벨은 셀 수만큼의 행을 갖는 룩업표와 같다.
셀몫의 크기 자체는 합격 조건이 아니다 -- 유지율을 지배하는 축은 벤치마크에 따라 다르며,
판정은 셀 평균을 제거한 잔차가 국면으로 설명되는지로 한다. 게이트는 배포 시점에 청크마다
결정하므로 셀 평균만 담은 라벨은 어느 경우에도 쓸 수 없다.

**C2. 한 번에 하나의 문구만 변경한다.** 문항 사이에 간섭이 있어 동시 변경 시 기여를
분리할 수 없다.

**C3. 장면 집합은 국면균등이어야 한다.** 자연 빈도로 표집하면 드문 국면의 표본이 작아
그 국면의 추정이 불안정하다.

**C4. 등급 분포를 저장해야 한다.** 정수 등급만 저장하면 conf 의 치역이 이산이 되어
$\tau$ 가 식별되지 않는다.

**C5. 가중은 라벨링 이후에 결정한다.** 등급과 기댓값 등급이 보존되어 있으면 가중은
재계산 가능하다. 라벨링 이전에 고정해야 하는 것은 문구와 계산 사실이다.

**C6. 문구 수정 전에 해당 문항이 묻는 대상이 화면에 관측 가능한지 확인한다.**

**C7. 발동률은 그 문항이 발동해야 할 국면 안에서 읽는다.** 전체 발동률이 낮은 것과
대상 국면에서 발동하지 않는 것은 다른 상태이며, 후자만 결함이다.

**C8. 4 의 판정에 불합격한 실행의 라벨은 이후 진단의 근거로 쓰지 않는다.**

**C9. 실행 설정을 라벨과 함께 기록한다.** 문항 부분집합을 바꾸면 A.1 의 정규화에 의해
유효 가중이 달라지므로, 선언된 가중만으로는 그 실행이 사용한 가중을 복원할 수 없다.

**C10. 계산 사실은 임계 판정을 마친 범주값으로 제공하고, 문장 수를 고정한다. 임계는
해당 녹화본에서 측정한다.** 다른 녹화본에서 측정한 임계는 분포가 달라 한 범주가 비거나
경고가 과다 발생한다.

## A.6 하네스 (실행 소프트웨어)

두 문항 판의 채점 결과가 비교 가능하려면 아래가 실행 사이에 고정되어야 한다. 하네스는
이것을 고정하고 실행마다 함께 기록한다.

| 고정 대상 | 내용 |
|---|---|
| 판정기 | 모델 식별자와 리비전, dtype, 디코딩(그리디), 최대 생성 토큰 |
| 응답 경로 | 텍스트 생성 후 파싱. 등급 토큰 확률을 함께 반환 |
| 장면 집합 | 시드, 국면당 개수, 에피소드당 상한 |
| 지표 | A.1 의 정의와 부트스트랩·순열 설정 |
| 문항 모듈 | 문구·부호·가중·등급표를 한 파일에 두고 버전으로 지정 |
| 배치 폭 | 값에 따라 부동소수점 끝자리가 달라지므로 기록 |

실행마다 위 설정과 문구 해시를 라벨과 함께 직렬화한다. 문항 부분집합을 바꾸면 A.1 의
정규화에 의해 유효 가중이 달라지므로, 선언된 가중만으로는 그 실행이 사용한 가중을
복원할 수 없다.

```bash
python scripts/<bench>_phase.py --sheet                    # 1
python scripts/build_phase_balanced_scenes.py <n>          # 2
CHECKS=<mod> python scripts/gp_conf_check.py <port> <scenes.json> <out.jsonl>   # 3
python scripts/phase_scorecard.py <out.jsonl> [...]        # 4
python scripts/fit_phase_weights.py <out.jsonl>            # 6
sbatch --array=0-15 run_scripts/label/sbatch_<bench>_full.sh                    # 9
python scripts/<bench>_to_parquet.py <labels_dir>                               # 9
```
